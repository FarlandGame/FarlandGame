## 作品紹介

### [Farland Auto Clicker](https://github.com/FarlandGame/Farland-Auto-Clicker)

ペルシャ語のインターフェースを備えた Windows 用オートクリッカーです。左右のクリック速度を個別に設定でき、切り替え用ホットキー、4 種類のテーマ、緊急停止に対応しています。

**使用技術：** Python、Tkinter、Windows API、PyInstaller。

[プロジェクトを見る](https://github.com/FarlandGame/Farland-Auto-Clicker) · [Windows 用をダウンロード](https://github.com/FarlandGame/Farland-Auto-Clicker/releases/latest/download/Farland-Auto-Clicker.zip) · [日本語の使い方](https://github.com/FarlandGame/Farland-Auto-Clicker/blob/main/docs/README.ja.md)
