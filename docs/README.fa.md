من **بردیا علیزاده** هستم؛ ملقب به **کبیر** و شناخته‌شده با نام هنری **Farland_game**. این صفحه محل معرفی پروژه‌های نرم‌افزاری و آثار خلاقانهٔ من است.

## نمونه‌کارها

### [Farland Auto Clicker](https://github.com/FarlandGame/Farland-Auto-Clicker)

اتوکلیکر ویندوز با رابط فارسی، تنظیم مستقل کلیک چپ و راست، میانبر قابل تغییر، چهار تم و توقف اضطراری.

**فناوری‌ها:** Python، Tkinter، Windows API و PyInstaller.
