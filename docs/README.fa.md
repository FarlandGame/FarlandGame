# بردیا علیزاده · Farland_game

[English](https://github.com/FarlandGame) | [日本語](https://github.com/FarlandGame/FarlandGame/blob/main/docs/README.ja.md) | [فارسی](https://github.com/FarlandGame/FarlandGame/blob/main/docs/README.fa.md)

من **بردیا علیزاده** هستم؛ ملقب به **کبیر** و شناخته‌شده با نام هنری **Farland_game**. این صفحه محل معرفی پروژه‌های نرم‌افزاری و آثار خلاقانهٔ من است.

## نمونه‌کارها

### [Farland Auto Clicker](https://github.com/FarlandGame/Farland-Auto-Clicker)

اتوکلیکر ویندوز با رابط فارسی، تنظیم مستقل کلیک چپ و راست، میانبر قابل تغییر، چهار تم و توقف اضطراری.

**فناوری‌ها:** Python، Tkinter، Windows API و PyInstaller.

[مشاهدهٔ پروژه](https://github.com/FarlandGame/Farland-Auto-Clicker) · [دانلود نسخهٔ ویندوز](https://github.com/FarlandGame/Farland-Auto-Clicker/releases/latest/download/Farland-Auto-Clicker.zip) · [راهنمای فارسی](https://github.com/FarlandGame/Farland-Auto-Clicker/blob/main/docs/README.fa.md)
