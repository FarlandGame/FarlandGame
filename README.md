## Featured work

### [Farland Auto Clicker](https://github.com/FarlandGame/Farland-Auto-Clicker)

A Windows desktop auto clicker with a Persian interface, separate left/right click settings, customizable hotkeys, four themes, and an emergency stop.

**Built with:** Python, Tkinter, Windows API, and PyInstaller.
