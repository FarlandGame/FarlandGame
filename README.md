## Featured work

### [Farland Auto Clicker](https://github.com/FarlandGame/Farland-Auto-Clicker)

A Windows desktop auto clicker with a Persian interface, separate left/right click settings, customizable hotkeys, four themes, and an emergency stop.

**Built with:** Python, Tkinter, Windows API, and PyInstaller.

[Explore the project](https://github.com/FarlandGame/Farland-Auto-Clicker) · [Download for Windows](https://github.com/FarlandGame/Farland-Auto-Clicker/releases/latest/download/Farland-Auto-Clicker.zip) · [日本語の説明](https://github.com/FarlandGame/Farland-Auto-Clicker/blob/main/docs/README.ja.md) · [توضیحات فارسی](https://github.com/FarlandGame/Farland-Auto-Clicker/blob/main/docs/README.fa.md)
